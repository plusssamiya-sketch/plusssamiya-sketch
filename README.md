## How the Repositories Are Organized

- Each project has a root `README.md` with the question, method, run command, and file map.
- `code/00_master.*` is the starting point for the workflow.
- `data/raw/README.md` explains what the sample files represent and where restricted source files would normally sit.
- `docs/` keeps data dictionaries, method notes, and confidentiality notes.
- `paper/` or `memo/` contains the short writing sample.
- `output/` keeps generated tables and figures when they can be shared.
